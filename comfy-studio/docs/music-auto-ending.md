# 자동 길이와 보컬 성별

사용자 요청: 길이 슬라이더로 만든 노래가 끝에서 끊기는 문제를 해결하고, 보컬 성별 선택을 추가한다. 새 생성은 사용자가 초수를 정하지 않고 `자동·여성·남성` 보컬 특성을 선택한다. 연주곡에는 보컬 선택을 표시하지 않는다. 성별은 모델의 보컬 스타일 지시이며 특정 목소리를 보증하지 않는다.

설치된 ComfyUI의 ACE-Step 1.5 경로는 오디오 코드 최소·최대 토큰을 동일하게 고정하고, 별도 노드에서 고정 길이 latent를 만든다. 공식 ACE-Step의 `duration=-1` 옵션을 이 경로에 넣는 것만으로 자동 길이가 되지 않는다.

전용 `ComfyStudioMusicAuto` 노드는 기존 텍스트 인코더와 ComfyUI의 모델 로딩·디바이스 문맥을 사용한다. 모델이 가사와 분위기에서 계획한 duration 메타데이터를 오디오 계획 프롬프트에 전달하고 EOS 선택을 허용한다. 끝 신호까지 만들어진 5Hz 오디오 코드 수로 실제 길이와 25Hz latent 크기를 계산한다. 그 길이에 맞는 텍스트 조건을 다시 인코딩하며, 메타데이터 계획과 오디오 코드 생성은 각각 한 번 실행한다. 기존 8스텝 샘플링, 타일 VAE, MP3·FLAC 저장 경로는 유지한다.

최소 15초 이후 EOS를 허용하고, 기존 PC에서 검증한 120초 분량을 내부 자원 예산으로 사용한다. 이 값은 곡을 강제로 자르는 출력 길이가 아니다. 예산을 다 써도 끝 신호가 없으면 확산·파일 저장 전에 실패시키고, 잘린 결과를 제공하지 않는다. 가사를 자동으로 고치거나 뒤에 가사를 추가하지 않는다. 분위기 설명에 자연스러운 곡 마무리와 선택한 보컬 특성을 전달한다.

새 작업 입력은 `durationMode: auto`와 `vocalGender`를 사용한다. 과거 길이 지정 작업의 입력과 결과는 그대로 보존하고 같은 작업 번호의 재요청·복구도 유지한다. 과거 작업을 폼으로 불러올 때만 새 자동 설정으로 변환한다. 옛 화면에서 새 작업 번호로 고정 길이를 제출하면 새로고침을 안내한다. 완료 결과에는 실제 길이와 끝맺음 검증 여부를 보관하며, 새 자동 작업에 끝맺음 증거가 없으면 재생 결과로 표시하지 않는다.

노드 소스는 `comfy_nodes/music_auto`에 있다. `scripts/install-music-auto.ps1`은 이전 파일을 비공개 `.data`에 백업하고 정해진 세 파일만 설치한다. ComfyUI 본체 파일이나 기존 노드를 수정하지 않는다. 설치 후 대기열이 비었을 때 ComfyUI를 재시작해야 한다. 새 노드가 없거나 자동 끝맺음·양쪽 모드·보컬 선택의 실측 인증이 없으면 운영 API에서 새 생성을 비활성화한다.

검증은 EOS가 예산 전에 나온 길이와 실제 파일 길이 일치, 종료 신호 없는 경우 파일 미생성, 양쪽 모드와 여성·남성·자동 보컬 전달, 원문 가사 보존, 과거 작업 복구, 길이 슬라이더 제거를 포함한다.

구현 비교 근거: 공식 ACE-Step `acestep/llm_inference.py`(ca1e85fe9430179831e6bc6be790c332190a3866)는 오디오 코드 앞의 assistant turn을 열어 두고 CFG 비조건 입력을 `NO USER INPUT`으로 만든다. 설치된 ComfyUI 기본 템플릿은 미리 turn을 닫으므로 전용 노드에서는 공식 학습 형식을 사용한다. 자동 길이일 때 공식 경로처럼 모델이 먼저 누락된 duration 메타데이터를 계획한다. 계획은 출력 강제 길이가 아니며, 실제 오디오 코드의 EOS로 최종 길이를 계산한다. PC 예산 밖의 계획은 줄여서 저장하지 않고 실패시킨다.

2026-10-18 RTX 3090 실측: 여성 44.8초 / 남성 55.0초 / 자동 보컬 44.6초 / 연주곡 109.2초에서 EOS로 완료. 8개 MP3·FLAC을 직접 디코딩한 길이가 기록과 일치했다. 네 실행의 최대 GPU 메모리는 12,793MiB, 최대 시스템 메모리 점유는 약 26.6GiB였다. 종료 신호 없이 예산을 소진한 실행에서는 확산·파일 저장 노드가 실행되지 않고 실패하는 것도 확인했다. 모델의 보컬 성별 지시는 선택한 특성을 유도하며 항상 같은 목소리나 성별 표현을 보증하지 않는다.
