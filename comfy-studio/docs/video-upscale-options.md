# 영상 확대 선택

출력 해상도와 확대 방식을 따로 선택한다. 기본값은 720p, 7초, 빠른 확대다. 빠른 확대는 생성된 864×480 MP4를 FFmpeg Lanczos와 H.264로 확대하고 AAC 오디오를 그대로 복사한다. 출력 화면비에 맞춰 중앙 크롭하며 원본 MP4도 보관한다. 480p는 확대하지 않는다.

AI 보정을 선택하면 기존 영상 latent 업스케일과 6스텝 분할 보정을 적용한다. 이때도 보정 전 원본 MP4를 별도로 저장한다. 1080p AI 출력은 720p AI 보정 뒤 Lanczos로 확대한다.

완성된 빠른 확대·480p 결과에서는 보관된 원본으로 별도의 AI 보정 작업을 만든다. 원본 MP4의 프레임·오디오를 VAE로 인코딩하고 보정 단계만 실행한다. 최초 20스텝 영상 생성 샘플러는 이 그래프에 포함되지 않는다. 마지막에는 원본 AAC 패킷을 다시 결합한다. 기존 결과와 프롬프트, 원본 작업 번호는 바뀌지 않는다.

길이 상한은 기존 실측값인 480p 10초, 고해상도 7초를 유지한다. 7초를 넘는 원본에는 후속 AI 보정을 제공하지 않으며 길이를 조용히 자르지 않는다. 과거 기록에서 확대 방식이 없으면 고해상도는 기존 AI 방식으로 해석한다. 새로운 요청의 기본값은 빠른 확대다. 후속 작업을 복구한 뒤 일반 생성 버튼을 누르면 새 영상 생성으로 처리한다.

비공개 원본 스트리밍과 후속 보정 API는 로그인, 동일 출처 검사, UUID·입력 검증, 작업 번호 기반 중복 방지를 사용한다. 원본과 최종 결과는 HTTP Range·HEAD·no-store를 지원한다. 필요한 노드·모델·인코더가 없거나 실측 인증이 없으면 새 작업을 차단한다.

실측 자료는 비공개 `.data/video-upscale-verification`에 보관한다. 기존에 검증한 텍스트·이미지 480p 원본을 각각 720p·1080p로 실제 출력했다. 네 출력 모두 243프레임, 24fps, 10.125초이며 전체 프레임 디코딩과 원본 대비 AAC 패킷 일치를 확인했다. 서비스에 공개하는 고해상도 상한은 보수적으로 7초를 유지한다.

로컬 Chrome에서 기본 빠른 확대, AI 선택 후 입력 모드 전환 시 선택 유지, 480p 선택 시 기본 방식 복귀, 길이 상한 초과 안내와 제출 차단을 확인했다. 기존 Next.js 네이티브 의존성 재배치 문제를 피하도록 개발·운영 명령 모두 공식 Webpack 옵션을 사용한다.
