# 노래 생성

현재 자동 길이·보컬 성별 변경은 [자동 끝맺음 문서](music-auto-ending.md)를 따른다. 아래 길이 선택과 초기 실측은 최초 구현 버전의 기록이다.

기존 이미지·영상 스튜디오와 같은 생성·복구 흐름으로 `/music`을 제공한다. 설치된 ACE-Step 1.5 Turbo AIO(Comfy-Org 배포 Apache-2.0)를 재사용하며 추가 모델 다운로드나 라이브러리 설치는 없다.

보컬곡은 분위기 설명, 직접 작성한 가사, 한국어·영어·일본어 중 노래 언어, 길이를 선택한다. 연주곡은 가사를 제외하고 `[Instrumental]` 조건과 보컬 제외 설명을 사용한다. 기본은 한국어 보컬곡·60초이고 길이는 15초 단위로 15~120초다. 가사 자동 작성과 참조 음원·리믹스는 이번 범위에 포함하지 않는다.

분위기 설명만 기존 Google Cloud Translation 서비스로 영어 번역한다. 가사는 공백과 줄바꿈을 포함해 원문 그대로 음악 조건에 전달한다. 저장 기록과 화면에도 사용자가 입력한 원문을 유지한다. 번역 후 길이가 늘어나는 경우 원래 입력 제한을 다시 적용하지 않는다.

저장된 음악 워크플로의 8스텝·CFG 1·Euler·simple 설정을 확인한 뒤 동일 시드를 텍스트 조건과 샘플러에 사용한다. 선택한 길이는 조건 인코더와 오디오 latent 양쪽에 적용한다. VAE 디코딩은 타일 512·겹침 64로 나누고, 같은 오디오를 320kbps MP3와 FLAC으로 저장한다. 웹 플레이어는 MP3를 재생한다. FLAC은 압축 손실 없이 저장된 결과이며 생성 품질이나 마스터링 품질을 보증하는 의미는 아니다.

음악 작업은 이미지·영상 기록과 구분해 저장한다. 제출 전에 작업 번호와 입력을 기록하고 같은 번호의 재요청은 기존 결과를 돌려준다. 접수 응답이 끊기면 ComfyUI의 큐·실행 기록에서 원래 생성 번호를 복구한다. 생성 중 새로고침해도 동일 작업과 원문 가사를 복구한다. 입력·파일 경로·형식·UUID를 검증하고 API는 인증과 동일 출처 검사를 적용한다. 비공개 오디오는 Range·HEAD·no-store를 지원한다.

2026-10-18 실측: RTX 3090 24,576MiB, RAM 약 64GiB, 9.34GiB AIO 체크포인트. 다른 사용자 작업을 취소하지 않고 빈 대기열에서 순서대로 실행했다.

| 입력 | 요청 길이 | 완료까지 | 관찰 GPU 최대 | 결과 |
|---|---:|---:|---:|---|
| 한국어 보컬 | 120초 | 약 56초 | 20,438MiB | MP3·FLAC 성공 |
| 연주곡 | 120초 | 약 49초 | 13,155MiB | MP3·FLAC 성공 |
| 연주곡 | 15초 | 약 7초 | 11,555MiB | MP3·FLAC 성공 |

여섯 파일 모두 전체 디코딩으로 요청과 동일한 길이, 48kHz 스테레오, 무음이 아닌 신호를 확인했다. GPU는 2초 간격의 전체 장치 표본이며 순간 피크를 놓칠 수 있고 모델 전환·캐시의 영향도 포함한다. 한 장면의 성공으로 모든 음악의 품질·가사 발음·실행 시간을 보장하지 않는다. 원본 파일·측정 자료는 비공개 `.data/music-verification`에 보관한다. 두 모드의 120초 검증 인증이 없으면 운영 API는 생성을 비활성화한다.

Chrome에서 보컬·연주곡 전환 후 입력 가사 유지, 최소 길이 선택, 실제 15초 보컬 생성 도중 새로고침 후 같은 작업과 가사 복구, 완성 결과와 MP3·FLAC 링크, 브라우저 실제 오디오 재생을 확인했다. 독립 코드 리뷰와 음악 입력·변환·저장·복구·미디어·API 테스트를 수행했다.

최종 코드 검증은 테스트 85개, 타입 검사, lint 오류 0개(기존 경고 8개), Webpack 운영 빌드다. 실제 빌드 HTTP에서 MP3·FLAC의 로그인 보호, Range 206·HEAD 200·잘못된 Range 416·no-store, 다운로드 파일의 SHA-256 일치, 동일 작업 재요청 시 원래 생성 번호 유지, 잘못된 출처 403, 120초 초과 입력 400을 확인했다. 같은 빌드에서 기존 영상 기능의 인증·부분 재생과 검증 설정도 통과했다.
